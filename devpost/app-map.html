MalariaScope App Map

A pocket guide to how the app works and where to change things. Snapshot of commit 39b58ed (19 Oct 2026); the code may have moved on since.

What the app does

A lab technician uploads one photo per microscope field of a thick blood smear. The app circles white blood cells (blue) and parasites (red), the technician corrects mistakes, and the app keeps the WHO running count until it can report parasites per µL.

The page

public/: screens, photo upload, drawing the circles, corrections, report. Keeps the slide in memory only.

The analyser

app.py + malariascope/analysis.py: a small Python server that finds the cells in one photo with OpenCV.

The WHO rule

public/protocol.js: decides "another field", "go to 500 WBC" or "enough", and computes the density.

The proof

tools/: download the NLM images, tune thresholds on 6 patients, measure accuracy on 4 others.

One action, end to end: confirming a field

Code route (3 stops)

Reference route Open the project in your editor and search for each anchor.

1

public/app.js → function analyse(resized)

When you upload a photo (or press "Next sample field"), the page shrinks it to 1600 px if needed and posts it to /api/analyze. The answer is a list of circle positions, stored as state.current and drawn on the canvas.

Key lines 
form.append("image", resized.blob, "field.jpg");
return fetch("/api/analyze", { method: "POST", body: form })
2

malariascope/analysis.py → def analyze, then def detect_wbc and def detect_parasites

White blood cells are big, very saturated purple blobs. Parasites are tiny dark dots found with a "black-hat" filter, then filtered by size, roundness, colour and darkness, and merged when two pieces belong to one ring. The thresholds come from malariascope/params.json, written by tools/tune.py.

Key lines 
wbc, wbc_blob = detect_wbc(hsv, mask, p)
parasites = detect_parasites(img, hsv, mask, wbc_blob, p)
3

public/protocol.js → function guidance(session)

After "Confirm field", the totals go through the WHO rule: under 200 WBC keep going; at 200 with 100+ parasites stop; with fewer than 100, extend to 500. guidanceText() in app.js turns that decision into the English or French message. Tested in tests/protocol.test.mjs.

Key lines 
if (parasites >= PARASITE_THRESHOLD) {
  return { target: FIRST_TARGET, remainingWbc: 0, canFinish: true, ... };
}

To change this, start here

  • Any text on screen, in English or French → public/i18n.js (one key per sentence, same key in en and fr).
  • Colours, spacing, phone layout → public/styles.css (colour variables at the top, phone rules under @media (max-width: 800px)).
  • Circle colours on the photo → COLORS at the top of public/app.js.
  • The WHO thresholds (200 / 500 WBC, 100 parasites, 8,000 WBC/µL) → constants at the top of public/protocol.js; rerun node --test tests/protocol.test.mjs.
  • Detection sensitivity → malariascope/params.json, ideally by rerunning tools/tune.py then tools/evaluate.py so the accuracy page stays honest.

A practice to reuse

Measure on data the tool never saw, in the same conditions as real use. Thresholds were tuned on 6 patients and judged on 4 others (tools/split.py). When the sample slide in the browser found far fewer parasites than the evaluation predicted, the cause was JPEG re-compression of tiny dots; tuning and evaluation were then redone on images compressed exactly like an upload (tools/annotations.py → load_image), and the browser and the evaluation agreed (32,995/µL in both). On any project with a "how good is it?" claim, keep a held-out set and check the number end to end through the real app, not only in a script.
